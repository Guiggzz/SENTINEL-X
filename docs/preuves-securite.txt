===== Anti-spoofing visage (vivacité) — 2026-10-06 =====
Objectif : une photo imprimée ou un écran (téléphone/PC) montrant une personne enrôlée ne doit
jamais être accepté comme « connu ».

Méthode (vision/face_liveness.py, CPU, OpenCV DNN) :
- Modèle passif Silent-Face-Anti-Spoofing (Minivision, Apache-2.0) : MiniFASNetV2 (échelle 2.7) +
  MiniFASNetV1SE (échelle 4.0), entrées 80x80 BGR 0..255, softmax 3 classes [photo, vrai, écran]
  moyenné ; score « vivant » = probabilité de la classe vrai visage.
- Modèles ONNX (QingHeYang/Silent-Face-Anti-Spoofing-onnx, commit 584d442) épinglés par SHA-256
  dans fetch_face_models.py, hors git ; sorties vérifiées identiques aux poids .pth officiels
  (écart < 1e-6 ; SHA-256 du .pth V2 = celui publié en amont).

Portillon d'identification (vision/identity.py, machine d'états testée avec horloge factice) :
- repos -> personne (YOLO ou visage) -> 2 bips courts « identifiez-vous » (action beep existante,

- visage connu ET vivant stable 0,5 s -> « Autorisé : <nom> » (bip court + LED verte), maintenu tant

- plus personne depuis 5 s -> repos (identify_end) ; pas de nouveau bip pour une présence continue.
